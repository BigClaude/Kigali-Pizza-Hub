Murakaza neza / Welcome!

Iyi dossier (folder) irimo urubuga rwose rwa ITALIANO PIZZA Kigali.
Yakozwe mu buryo bworoheye buri wese (Beginner friendly), 
idafite JavaScript cyangwa ibindi bikorwa bigoye (Pure HTML5 & CSS3).

------------------------------------------------------------
UBURYO BWO GUFUNGURA URUBUGA (HOW TO OPEN THIS WEBSITE):
------------------------------------------------------------
1. Kanda kabiri (Double-click) kuri dosiye yitwa:
   -> index.html
2. Izahita ifungukira muri browser yawe (Google Chrome, Safari,
   Microsoft Edge, Firefox, cyangwa Opera).
3. Nta internet cyangwa serveur bikenewe kugira ngo urebe
   amapaji yose, amafoto, n'imigaragarire yayo!
