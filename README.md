# 🔥 ITALIANO PIZZA — Kigali, Rwanda
### Complete Standalone Website Package (Pure HTML & CSS)

A modern, responsive, high-performance landing website for **ITALIANO PIZZA** in Kigali, Rwanda.

Built with **100% pure HTML5 and CSS3** (Zero JavaScript, no complicated frameworks, beginner-friendly).

---

## 🚀 How to Run Locally

You don't need Node.js, Python, or any web server to view this site:

1. **Extract / Open** this `italiano-pizza-website` folder.
2. **Double-click `index.html`** in your file manager.
3. It will immediately open in Google Chrome, Safari, Edge, Firefox, or Brave.
4. All 5 pages, CSS transitions, hover dropdowns, and high-definition pizza photos will work flawlessly offline.

## ✨ Features

- Pure CSS checkbox hacks for login modal, pure CSS `:hover` states for sub-menu pizza sizes, and CSS target/radio tabs.
- **Pure CSS Sub-Menu**: Hovering over "Menu" reveals pizza size breakdown (Personal 10", Classic 12", Shared 14", Grande Festa 18").
- **Authentic Rwandan Context**: Addresses in Nyarutarama (KG 9 Ave) and Kimihurura (KG 674 St), local phone numbers (+250 788 456 789), and descriptions in Kinyarwanda & English.
- **2-Minute Video Summary**: Interactive video showcase displaying authentic pizza making from 72h fermentation to stone-baked bubbling crust.
- **No Complex Dependencies**: Can be hosted on any web server, GitHub Pages, Netlify, cPanel, Vercel, or opened offline.
